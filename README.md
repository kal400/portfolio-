# Kalab Awoke — Portfolio

A fast, responsive, dependency-free portfolio website built with semantic HTML, CSS, and a small amount of JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

## Customize

- Update the copy and project cards in `index.html`.
- Adjust the visual system in `styles.css`.
- Replace `hello@kalab.dev` and the social link with your preferred contact details.
